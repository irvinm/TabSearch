Privacy & Permissions

IMPORTANT

When using classic Tab Hiding mode, this extension uses Firefox's tabs.hide() API to temporarily filter your open tabs. Firefox requires your explicit permission to hide tabs.

First-Time Permission Setup

  • On first use, TabSearch presents a setup prompt. Clicking Enable Tab Hiding (or closing the popup) prompts Firefox's native permission doorhanger.
  • To allow TabSearch to filter tabs, click “Keep tabs hidden” in the Firefox dialog.
  • This is a one-time requirement by Mozilla to ensure you are aware of the tab-hiding capability.
Notes & Privacy Guarantees:
  • 100% Local: No tab data, titles, URLs, or search terms are ever transmitted to external servers. All search operations run strictly inside your browser.
  • Temporary: Tabs are only hidden while an active search is open and are immediately restored when the popup closes or the search is cleared.
  • Safe by Design: Your currently active tab and pinned tabs are strictly protected and never hidden.
  • Disable Initial Probe: Once permission is granted, you can check “Disable initial hide action” in the popup options if you do not want background probes running on startup or popup close.
  • Virtual Dashboard Alternative: If you prefer not to hide tabs at all, enable “Virtual Search Results Dashboard” in options to browse and jump between matching tabs in a dedicated tab.
MDN: tabs.hide()
